# dsh-toolbox 输出归档

本目录保存所有与 `dsh-toolbox` 项目相关的助手最终回复。

## 规则

- **触发范围**：每一轮只要内容与 `dsh-toolbox` 项目相关，就归档。
- **归档对象**：最终回复正文；不归档工具调用、内部推理、临时命令输出。
- **内容一致性**：文件正文与聊天输出一致，不二次改写。
- **多段回复**：同一轮的多段内容合并为一份，不拆成多个文件。
- **命名**：`YYYYMMDD-HHmm-<主题>.md`。
- **索引**：本文件维护规则与归档列表。
- **非项目内容**：与 `dsh-toolbox` 无关的回复不归档。
