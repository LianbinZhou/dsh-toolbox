## 2. 封板前必须改的两处文档

### 2.1 README 写的默认保留期是 14 天，代码默认是 7 天

`README.md` 当前写：

```text
默认保留 14 天
```

但代码里：

```js
TRASH_KEPT_DAYS_DEFAULT = 7
```

`S4-封板简报` 自己也写默认 7 天。  
这是开源文档的明显矛盾，必须改成：

- 默认 **7 天**；
- 可选 **3 / 7 / 14 / 30 / 60**；
- 范围 **1–90**。

### 2.2 简报写 v0.4.0，package.json 仍是 0.1.0

`docs/S4-封板简报.md` 标题写：

```text
正式封板（v0.4.0）
```

`package.json`：

```json
"version": "0.1.0"
```

二选一：

- 把包版本升到 `0.4.0`（并决定是否打 tag）；
- 或删掉简报里的 `v0.4.0`，只写“S4 封板 / 0.1.0”。

不要两个版本号同时存在。开源用户会先看 `package.json`。

### 2.3 `verify-trash` 的“剩余≈见证据4”只是提示

当前输出里 journal 条目显示：

```text
剩余≈见证据 4 天
```

因为 journal 记录本身没有 `keptDays`，脚本只能用接口的 `keptDays`。  
这是工具文案问题，不是功能问题；可以在 S5 顺手修。
