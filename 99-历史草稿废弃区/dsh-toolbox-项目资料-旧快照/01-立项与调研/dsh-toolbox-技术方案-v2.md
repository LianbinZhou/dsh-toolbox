### 2.1 为什么改用 esbuild（对应报告 5.1）

报告说得对：5 个功能里有大量同名顶层标识符（`h`、`t`、`NS`、`state`、`copyText`、`pass`、`injectStyles`…），塞进一个 IIFE 必然 `SyntaxError: Identifier 'h' has already been declared` —— **整个 `client.js` 不执行，6 个功能全灭，连设置表单都没有**。

esbuild 一次解决四个问题：作用域隔离、文件间分号、`return` 位置、tree-shaking。代价只是多一个 devDependency。

```js
// tools/build.mjs
import { build } from 'esbuild'
await build({
  entryPoints: ['src/client/index.js'],
  outfile: 'client.js',
  bundle: true,
  format: 'iife',
  target: ['chrome110'],
  minify: false,          // 保留可读性，排障优先
  legalComments: 'none',
  banner: { js: '/* dsh-toolbox client — generated by tools/build.mjs; do not edit */' },
})
```

**`client.js` 提交进仓库**，并保留 `build-fresh.test.mjs`：重跑一次与仓库逐字节比对，不一致就红 —— 直接治"改了源码忘了构建"（这条我从 v1 保留，报告也认可）。

> esbuild 需要从 npm 装进本包 `devDependencies`。如果 profile 的供应链策略不允许，退路是 `@deepseek-ai/dsh` 自带的那份（需先验证能解析）；**两步都要在开工第一天验掉**。

## 3. 问题一：客户端路由（按 8.2-3/4 重写）

### 3.1 feature 契约（v2 加强版）

```js
// src/client/registry.js
export const CONTRACT = 'mount(ctx, env) -> disposer'

export function defineFeature(spec) {
  if (!spec.id || !spec.configKey) throw new Error('feature needs id + configKey')
  if (typeof spec.mount !== 'function') throw new Error('feature ' + spec.id + ' has no mount')
  if (spec.reversible === undefined) throw new Error('feature ' + spec.id + ' must declare reversible')
  return spec
}
```

`reversible: false` 的功能（`plugin-zh`、`draft-saver`）**不得在拿到真实开关值之前挂载**（8.2-3 / 报告 2.3）。

### 3.2 事务化 mount（8.2-4）

```js
// src/client/scope.js
export function createScope() {
  const undo = []
  let closed = false
  return {
    track(disposer) {
      if (typeof disposer !== 'function') throw new TypeError('disposer must be a function')
      if (closed) { try { disposer() } catch {} ; return () => {} }
      undo.push(disposer)
      return disposer
    },
    dispose() {
      if (closed) return
      closed = true
      let first
      for (const d of undo.splice(0).reverse()) {
        try { d() } catch (error) { first ??= error; console.error(error) }
      }
      if (first) throw first
    },
  }
}
```

硬规矩：**没有走 `env.track()` 的副作用，不允许进容器。** 复合 disposer 也一律由 `scope.dispose()` 统一反向执行 + 每个独立 try/catch，杜绝"第一个抛错、后面全不执行"。

### 3.3 容器（8.2-3）

```js
// src/client/index.js
export default {
  inject: ['slots', 'locale'],
  apply(ctx) {
    let disposed = false
    let queue = Promise.resolve()
    const state = new Map()   // id -> 'mounting' | 'mounted' | 'off'
    const scopes = new Map()  // id -> scope
    const errors = new Map()

    const reconcile = (next) => {
      for (const f of FEATURES) {
        const want = next[f.configKey] === true   // 缺值 = 关
        const phase = state.get(f.id) ?? 'off'
        if (want && phase === 'off') {
          if (disposed) continue
          state.set(f.id, 'mounting')             // ← 先占位，防重入双挂
          const scope = createScope()
          try {
            f.mount(ctx, env(ctx, scope))
            state.set(f.id, 'mounted')
            scopes.set(f.id, scope)
            errors.delete(f.id)
          } catch (error) {
            errors.set(f.id, error)
            try { scope.dispose() } catch {}      // ← 事务回滚
            state.set(f.id, 'off')
          }
        } else if (!want && (phase === 'mounted' || phase === 'mounting')) {
          const scope = scopes.get(f.id)
          scopes.delete(f.id)
          state.set(f.id, 'off')
          try { scope?.dispose() } catch (error) { errors.set(f.id, error) }
        }
      }
    }

    const schedule = (next) => {
      queue = queue
        .then(() => { if (!disposed) reconcile(next) })
        .catch((error) => console.error('[dsh-toolbox] reconcile failed', error))
      return queue
    }

    // 1) 先用 localStorage 缓存的上一轮值（同步、可靠）
    schedule(cachedSwitches())

    // 2) 真实值到了再对齐；取消/卸载后不得再 mount
    readSwitches(ctx).then((v) => schedule(v)).catch(() => schedule({}))

    // 3) 订阅变更
    const offWatch = watchSwitches(ctx, (v) => schedule(v))

    ctx.effect(() => () => {
      disposed = true                      // ← 先置位
      try { offWatch() } catch {}
      queue = queue.then(() => {
        for (const [, scope] of scopes) { try { scope.dispose() } catch {} }
        scopes.clear()
        state.clear()
      })
    }, 'toolbox: dispose all features')
  },
}
```

**关键差异**：`state` 在 `mount` **之前**写 `mounting`，所以 `mount` 内部同步触发的事件再进来会看到 `mounting` 并跳过 —— 双挂路径被堵死。

## 4. 问题二：依赖注入与覆盖（8.2-8）

### 4.2 `session-query-sqlite` 的 patch（报告 6.3）

真相：patch 层是**静态**的，运行时开关**关不掉**它。且**匹配到的 override 会整体替换 config**。

v2 决策不变但要写进 README：**这条 patch 随 bundle 常驻**，只做无害的两件事（开官方全文检索、指定持久索引路径）。面板里必须写明：

> 「会话搜索」开关只控制**给 AI 的 `session_search` 工具**，不控制侧栏搜索是否走全文索引。

真要能关 → 拆第二个 bundle 当开关（v2 不做）。

### 4.3 兜底：guard 必须先判断工具名（报告 3.3）

```js
ctx.tools.guard((exec) =>
  exec?.name === 'session_search' && !config.sessionSearch.get()
```

漏了 `exec.name` 判断 = **把所有工具一起 deny**。denial 文案必须含"用户明确关闭 + 不要重试 + 替代路径"。

### 9.1 对 v2 的两处直接影响

1. **`ctx.inject` 返回的是 Fiber，不是普通 disposer** —— `env.track()` 要能接受 Fiber（调 `fiber.dispose()` 或 `await fiber` 后再 dispose），不能只接受函数。
2. **第 3 条不用再阻塞**：`namespace 不存在 / describe 为空 → 全部 off` 已经是硬规则。

## 11. 本次追加发现（写进 v2 执行纪律）

### 11.1 `references/practices.md` 里三条硬规则，两条会打到我们

| 官方原文 | 对我们的意义 |
|---|---|
| *"a throwing component **blanks your slot entry** (console: `slot entry crashed in '<slot>'`)"* | **这就是我那个空白页的官方解释**。→ 硬规矩：组件绝不许抛；兜底解析走 `safeParse`；卡片永远至少画一行。 |
| *"Do **not** `require('@deepseek-ai/dsh-client-ui-primitives')` or load any other Harness Client package as a module"* | 确认「一个包一个 client 文件、不许 require 兄弟包」，v1 设想的动态 require 彻底出局。 |
| *"Do **not** write DOM outside your component or append to `document.body`"* | ⚠️ **这条直接打到两个现有功能**：`plugin-zh` 改页面文本节点、`dsh-plugin-zh` 往 body 追加提示条 —— 都属于官方明确劝阻的做法。 |

### 11.2 所以 `plugin-zh` 要重新定位（新增决策项）

现状：它靠 MutationObserver 改**别人渲染出来的文本**。官方规则明确不鼓励；报告也指出它"关闭后不还原"。

v2 里给它两条路，**必须二选一**：

- **路 A（推荐）**：改成走官方 locale —— 用 `ctx.locale.register(ns, dict)` 注入描述翻译，**不碰 DOM**。前提是先验"能不能对别的包的描述生效"（Spike 时没验，需加一个 30 分钟小实验）。
- **路 B**：保留 DOM 方案，但按 8.2-5 做完整还原（WeakMap 原文 + 条件回写 + 摘监听 + 清全局），并在 README 里明说"违反官方 UI 指南，属技术债"。

**这个我建议先做路 A 的 30 分钟实验再定。**
