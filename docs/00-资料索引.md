## 规矩（已写进 AGENTS.md）

- 工作区根目录**只放文件夹**，不放散落文档
- 一个项目的文档**只住在它的仓库里**，不再建外部副本目录
- 归档动作 = 只读比对 → 列清单 → **移动不删除** → 哈希校验
