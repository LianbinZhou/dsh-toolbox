## 1. 已通过的部分

### 1.1 防腐层

- `createDshAdapter().selfCheck()` 现在真实探测全部服务；
- 空 ctx 返回 `ok:false`，`missing` 包含全部服务；
- `sessions` 明确为必需，`REQUIRED_SERVICES = ['slots','locale','sessions']` 与 root inject 一致；
- `probe()` 只读、不警告，`get()` 才记录/告警，职责清楚；
- `callOptional()` 吞掉缺失/异常，符合“可选方法”定位。

空 ctx 的 `selfCheck()` 假绿问题已解决。

### 1.2 可逆汉化

当前 `Map<node,{original,translated}>` + `pruneApplied()` 的方向是对的：

- `translateTextNode`：
  - 已记录且 `nodeValue === translated` → 跳过；
  - 否则删旧记录，把当前值当新原文重查；
- `restoreApplied`：
  - `isConnected === false` 跳过；
  - `nodeValue !== translated` 跳过，不覆盖 React 复用节点的新文本；
- `pruneApplied` 在每次 pass 末尾清 detached 记录。

这比原来的 `applied` 数组安全得多。  
`Map` 不是 `WeakMap`，但有 prune 后，长期停留页面不会无界增长；可以接受。

### 1.3 features.js

pluginZh 已变成：

```js
probe.bump('plugin-zh')
track('plugin-zh', env)
return mountPluginZhFeature(ctx, env)
```

语言判断、adapter、mount、dispose 都在 `plugin-zh.js`。  
`features.js` 不再出现 `ctx.locale`。  
这满足“加功能不改 index.js”的注册机制；`features.js` 仍会有 3 行通用包装，不是严格的一行，但可以接受。

### 1.4 lockfile / 版本

当前 profile：

- `package.json` 不含 `dsh-plugin-zh`；
- `node_modules/dsh-plugin-zh` 不存在；
- `pnpm-lock.yaml` 中 `dsh-plugin-zh` 为 0；
- `package.json` 版本 `0.5.1`，与简报一致。

这一项可以过。

## 2. 开工前必改：非中文界面仍会翻译

`plugin-zh.js` 当前：

```js
const enabled = String(locale).toLowerCase().startsWith('zh')
...
const begin = () => {
  if (disposed) return
  if (!documentRef || !documentRef.body) return
  runNow()                                  // ← 无条件
  if (enabled && typeof MutationObserver === 'function') {
    observer = new MutationObserver(schedule)
    observer.observe(...)
  }
}
```

`runNow()` 内部也没有检查 `enabled`。  
所以：

```js
mountPluginZh({ locale: 'en' })
```

在真实 DOM 上仍会执行一次翻译，然后才因为没有 observer 而停住。  
如果页面已经是中文，可能看不出；但如果界面语言是英文，插件说明会被翻译成中文——这是行为回归。

要求：

```js
const runNow = () => {
  if (disposed || !enabled) return 0
  ...
}
```

或：

```js
const begin = () => {
  if (disposed || !enabled) return
  ...
}
```

并补一条**真实 DOM/最小 document 测试**：

- `locale='en'` → 文本不变；
- `locale='zh'` → 文本变中文；
- `dispose` 后英文恢复。

现有 `mount · 非中文界面不工作` 只测了没有 DOM 的情况，抓不到这个 bug。

## 3. 手动真机验收要求

老板已批准用真机手点替代 Playwright，这点我同意；但手动验收必须覆盖：

1. **插件管理页打开时是中文**：开关开 → 描述变中文；

4. **页面内切换/重渲染后**（例如切换插件页 tab、刷新列表）：
   - 英文不能自己回来；

5. **界面语言为英文时**：插件不应翻译（对应上面的 bug）；

只要这 6 条有截图或录屏/日志，第 6 条“真浏览器测试”可以按手动验收放行。
